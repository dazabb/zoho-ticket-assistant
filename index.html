Set up Zoho autofill

Checking extension…

  1. Download extension and extract the ZIP.
  2. In Chrome, open chrome://extensions.
  3. Turn on Developer mode, then choose Load unpacked.
  4. Select the extracted MAU-Zoho-Extension folder.
  5. If you open index.html directly instead of using the start file, enable Allow access to file URLs in the extension's Details.

After connecting, click Create Ticket. Zoho opens with the form filled for you to review. The extension never submits tickets automatically.
