# MAU Operation Desk v1.6 — Simple View

## What changed
- Removed the free-tier label, repeated instructions, and extra technical guidance from the main screens.
- Removed Save HTML and Save TXT. Reports can be copied only.
- Monde: upload VPG and alerts CSVs, select date, generate, then copy subject or email. VPG details stay under **View VPG details**.
- Viber: upload tickets CSV, optionally paste previous message, generate, copy. Detailed corrections and warnings are still available under expandable sections.
- Existing support workflows, profile selection, personal Gemini key input, subject and account rules, and ticket follow-up logic are retained.

## Notes
This changes the interface and presentation only. Confirm ticket details and alerts before posting to customers or Viber. The Viber generator cannot reliably determine same-day closing times unless the CSV or previous update supplies confirmed timestamps.
