# MAU Operation Desk v3.0.3 — CSA Store Name

- CSA Generator now reads a Store Name / Branch Name / Outlet Name from the copied customer ticket and keeps it separate from Zoho Customer Company Name.
- The generated AMTI CSA shows the store name on its own line above the physical address in the existing Location Address section. The company name remains the customer company.
- Optional Edit ticket details now includes an editable Store Name field.
- In tickets with store names, unused blank Job Done / Resolution lines are adjusted so a typical six-task CSA remains on one page, without deleting any engineer tasks, signature boxes, or customer remarks.
- Individual CSA and batch ZIP downloads, plus all other features, remain unchanged.

Company Name: GABC_PENSHOPPE
Store Name: Penshoppe Gaisano Marketplace Roxas
Location Address: G/F Gaisano Marketplace Brgy. VIII, Roxas City Capiz
