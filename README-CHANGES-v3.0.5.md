# MAU Operation Desk v3.0.5 – CSA Company/Brand Matching

- Where Zoho supplies `Account Name` and `Customer Company Name`, the CSA uses the registered account for **Company Name**.
- Retail brand names are kept separate, when verifiable, and the original Store/Site is retained above the street address.
- The Brand field is editable in `Edit ticket details` and now populates the previously unused Brand cell of the CSA.
- Company fallback remains available for tickets with no Account Name.
- The engineer activities, visit schedule, and `#ticket.docx` format are unchanged.
