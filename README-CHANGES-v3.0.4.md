# MAU Operation Desk v3.0.4 — Flexible CSA details

- Supports alternate terms for customer/company, store/site/branch, office/warehouse/outlet, and service address.
- Recognizes task sections and plain customer instructions, while excluding tool-packing lists and copied email signatures.
- Keeps specific site separate from the customer company and shows **Store / Site** above its street address in the CSA.
- When source details cannot be reliably identified, leaves the field blank for manual review instead of inventing values.
- Existing DOCX template, employee workflow, Zoho extension, reports and batch processing remain available.
