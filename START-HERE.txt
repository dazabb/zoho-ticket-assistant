MAU OPERATION DESK v0.9 — PERSONAL GEMINI API KEYS

1. Extract all files to a folder.
2. Double-click START-MAU-DESK.bat (Windows + Node.js 20+), then open http://127.0.0.1:3000.
   Alternatively open index.html directly; some browsers may restrict local file API requests.
3. Select your pictured profile.
4. Click API key, then Get Gemini API key ↗ to open Google AI Studio (https://aistudio.google.com/apikey). Create or copy your personal key, return to MAU, and paste it into the field.
5. Click Save key and use the AI chat.
6. Click API key / Usage to see requests made through this browser, tokens reported by Google, and next reset.

No shared API key, MAU server AI connection, or .env file is needed.
If Remember my key is checked, the key is stored in this browser (unencrypted localStorage) for the selected picture profile and loaded next time on the same browser. Anyone with access to that browser can read/use it. Do not save keys on a shared/untrusted device. MAU picture profiles are not authentication; use a separate browser/OS account for privacy.

USAGE: App counters are local only; Google rate limits apply by Google Cloud project, including activity outside MAU. Daily request quotas reset at midnight Pacific Time. Confirm actual usage/limits at https://aistudio.google.com/usage.

CAUTION: Gemini is not guaranteed to be free. Use an eligible free-tier project without billing to avoid charges. Google free-tier submissions may be used to improve its products. Avoid confidential ticket data unless your organization's policy permits it.

The Zoho ticket assistant is a client-side tool; profile choices are not access controls. Host only in an approved environment. This version doesn't create a secure shared team login.
