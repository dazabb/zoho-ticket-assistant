# MAU Operation Desk v3.0 — simpler CSA and Zoho setup

- CSA: paste a ticket and choose **Download CSA** to create the DOCX directly.
- Use **Edit details first** only when you need to change ticket data; no plain-text review pane.
- Batch: choose **Add multiple tickets**, then download individually or all together.
- Removed technical extraction notes, built-in-template status text, and implementation details from the CSA screen.
- Zoho extension: **Refresh** reloads MAU so Chrome reconnects the extension. On a successful connection, installation steps are hidden.
- Chrome still requires manual unpacked extension installation; the page cannot install it automatically.
- Existing Monde Nissin, Viber, Gemini, and ticket mappings remain in the app.
